HomeLedger is a free, offline household budget planner that runs entirely in the browser: an editable monthly planner for income and expenses, an SVG spending donut, a 50/30/20 rule check, savings goals with computed finish dates, a 12-month projection, and realistic preset households — with no account, no tracking, and no network requests.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts
```

Then open http://localhost:8080 — or open `out/app/index.html` directly in any browser.
